
# Projeto ADOPET - App de Adoção de Pets

Aplicação Android desenvolvida em Java, para Projeto de extensão, com o objetivo de permitir o cadastro, gerenciamento e disponibilização de animais para adoção.

O projeto foi desenvolvido utilizando componentes nativos do Android, Firebase para autenticação e persistência de dados, Retrofit para consumo de APIs externas e serviços de armazenamento e gerenciamento de imagens.

# Descrição

Este projeto consiste em uma aplicação Android para gerenciamento e adoção de animais.

A aplicação permite que usuários realizem autenticação, gerenciem suas informações pessoais, cadastrem animais e disponibilizem pets para adoção. Também é possível visualizar animais cadastrados por outros usuários através de listas dinâmicas.

A aplicação utiliza o Firebase Realtime Database para persistência dos dados e Firebase Authentication para gerenciamento da autenticação dos usuários.

Para funcionalidades relacionadas a endereços, o projeto realiza requisições à API ViaCEP utilizando Retrofit e Gson.

O gerenciamento e carregamento de imagens é realizado através da biblioteca Glide.

A interface foi construída utilizando componentes AndroidX e Material Design, com navegação baseada em Fragments e Navigation Drawer.

# Funcionalidades

- Cadastro de usuários
- Login e autenticação
- Controle de sessão do usuário
- Edição de informações pessoais
- Cadastro de animais
- Cadastro de cães
- Cadastro de gatos
- Visualização de animais disponíveis para adoção
- Visualização de animais cadastrados pelo usuário
- Gerenciamento de fotos
- Consulta de endereço através do CEP
- Integração com API externa
- Navegação através de Navigation Drawer
- Exibição de dados utilizando RecyclerView
- Atualização dinâmica da interface
- Persistência de dados em nuvem

# APIs e comunicação

- Retrofit
- Gson
- REST API
- JSON
- ViaCEP API
